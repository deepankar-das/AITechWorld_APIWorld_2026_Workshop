# Bucket Classification

Common AgenticDevelopmentModel failure buckets:

- auth or session
- hydration or SPA render
- DB pool or concurrency pressure
- schema or data contract
- stale UI or E2E contract
- deploy or startup readiness
- missing credentials or environment

For each bucket capture:

- blast radius
- representative signatures
- first code touchpoint
- targeted rerun command
- counter-example that would refute closure
