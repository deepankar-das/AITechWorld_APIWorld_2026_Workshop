# AgenticDevelopmentModel Release Readiness

## When to use

Use this skill for final verification, release gating, rollback posture checks, and evidence-packet assembly.

## Workflow

1. Confirm the exact scope being released.
2. Verify that required gates are satisfied by evidence, not narrative.
3. Surface unresolved findings or environment gaps explicitly.
4. Package verification receipts, rollback notes, and approval state together.
