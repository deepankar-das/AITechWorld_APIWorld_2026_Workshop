# Task Packet Shape

Each structured packet should include:

- objective
- exact scope
- out-of-scope guardrails
- files or surfaces expected to change
- acceptance criteria
- required verification commands
- approval requirements
- open questions
- owner

Every execution row must have exactly one owner and explicit dependencies.
