# AgenticDevelopmentModel Implementation Plans

## When to use

Use this skill when drafting or revising implementation plans, feature specs with phased tables, or test-writing plans.

## Workflow

1. Choose the correct template family: feature/code or testing/remediation.
2. Use one-row-one-owner tables with exact file lists and explicit deps.
3. Keep descriptions behavioral and concrete: functions, routes, fields, expected outcomes.
4. Update progress summary and status rows as implementation advances.
