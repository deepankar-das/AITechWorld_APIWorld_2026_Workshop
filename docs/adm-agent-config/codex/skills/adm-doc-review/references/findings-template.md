# Findings Template

Use this review structure:

1. Findings
   - file and line reference
   - severity
   - concrete symptom
   - why it is wrong or risky
   - what evidence supports that claim
2. Open questions
3. Secondary summary only after findings

Do not lead with praise or overview when material findings exist.
