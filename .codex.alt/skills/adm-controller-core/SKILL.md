# AgenticDevelopmentModel Controller Core

## When to use

Use this skill when a request needs structured decomposition rather than direct implementation: PRD creation, plan synthesis, multi-lane execution, approval routing, or verification planning.

## Workflow

1. Normalize the request into explicit objective, scope, constraints, and evidence requirements.
2. Decompose into single-owner work packets with acceptance criteria and tests.
3. Separate authoring, review, convergence, verification, and release-readiness lanes.
4. Keep destructive actions and architecture changes behind explicit approval boundaries.
