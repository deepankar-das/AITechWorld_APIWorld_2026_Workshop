# AgenticDevelopmentModel Document Review

## When to use

Use this skill for reviews of product, architecture, testing, release, RCA, or implementation documents.

## Workflow

1. Review findings first, ordered by severity.
2. Distinguish `Verified`, `Inferred`, and `Unknown` claims.
3. Check for ownership ambiguity, unstated dependencies, closure overclaims, and missing verification.
4. Surface every unresolved issue explicitly; do not silently triage it away.
