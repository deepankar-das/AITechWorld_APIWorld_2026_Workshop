# Release Packet Checklist

A release packet should include:

- exact scope and commit range
- verification commands and outcomes
- unresolved issues or environment gaps
- rollback posture
- approval state
- follow-up items that were explicitly approved as post-release work

Do not mark a release green on partial closure or narrowed verification without approval.
